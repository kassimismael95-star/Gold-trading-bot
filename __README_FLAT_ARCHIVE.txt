Gold Trading Bot — flattened full-path filename archive

Each file is named using its repository-relative path, with every directory separator / replaced by __.
Example: apps/api/app.py becomes apps__api__app.py.

This archive is intentionally flattened so Android extractors show the full repository path in each filename.
It is NOT directly upload-ready for GitHub in this flattened form. To restore the repository, replace each __
separator that represents a directory with / and recreate those folders. Use FILE_PATH_MAPPING.txt as the exact mapping.
The source archive was preserved file-by-file; no source file contents were changed during repackaging.
